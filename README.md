# Aura Botanical

A clean, premium landing page for a transparent cognitive support supplement.

## Features

- Modern responsive landing page
- Hero section with clear product positioning
- Ingredient table with exact dosages
- Trust-focused design and checkout modal
- Mobile-friendly layout

## Files

- `index.html` — main landing page
- `README.md` — project overview

## Preview
